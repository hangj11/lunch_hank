# LunchFit

직장인의 점심 시간과 예산에 맞춰 메뉴를 탐색하고 선택하는 반응형 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 실행됩니다. 별도 빌드 과정이나 패키지 설치가 필요하지 않습니다.

## GitHub Pages 배포

사이트 파일은 저장소 루트의 `index.html`, `styles.css`, `app.js`입니다. `main` 또는 `master` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 GitHub Actions를 통해 Pages에 배포합니다. 저장소의 **Settings → Pages**에서 배포 원본을 **GitHub Actions**로 선택하세요.

배포 주소는 보통 `https://<GitHub 사용자명>.github.io/<저장소명>/` 형식입니다. 실제 주소는 GitHub Pages 설정의 배포 상태에서 확인할 수 있습니다.

## 데이터 안내

식당명, 사진, 가격, 거리, 평점, 리뷰 수, 대기시간, 지도 위치는 화면 시연용 샘플입니다. 실제 매장·지도·예약·주문 서비스와 연결되어 있지 않습니다.
